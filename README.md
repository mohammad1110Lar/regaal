# رگال (Regaal) — استایلیست هوشمند مد

رگال فروشگاه نیست؛ استایلیست است. کاربر موقعیتش را با یک جمله می‌نویسد (مثلاً «می‌خوام برم مراسم عزاداری»)،
وارد می‌شود، به چند سؤال کوتاه جواب می‌دهد و رگال در **محصولات موجود فروشگاه‌های معتبر پوشاک ایران** می‌گردد،
یک «استایل کامل» در سایز و بودجه‌ی او می‌سازد و اکسسوری هماهنگ پیشنهاد می‌دهد. خرید در سایت همان فروشگاه انجام می‌شود.
اگر چیزی که در ذهن دارد پیدا نشد، با **دوخت سفارشی** می‌نویسد چه لباسی می‌خواهد، از پینترست نمونه انتخاب می‌کند و سفارش را به خیاط می‌دهد.

## ۱. دیدن پیش‌نمایش

| روش | دستور | توضیح |
|---|---|---|
| با سرور (پیشنهادی) | `npm install` و `npm start` → `http://localhost:8080` | ورود با نشست، دوخت سفارشی با جست‌وجوی زنده‌ی پینترست، سفارش‌ها و «دیده‌شده‌ها» روی سرور |
| ساده | `index.html` را در مرورگر باز کنید | موتور داخل مرورگر؛ ورود آزمایشی؛ نمونه‌های آماده‌ی دوخت سفارشی؛ سفارش در همین مرورگر |
| کامل | `ANTHROPIC_API_KEY=… KAVENEGAR_API_KEY=… SESSION_SECRET=… NODE_ENV=production npm start` | Claude + پیامک واقعی |
| تک‌فایلی آفلاین | `python scripts/build_standalone.py --mode offline` → `dist/regaal-offline.html` | ۱۰٬۰۰۰ محصول متعادل از هر ۱۲ فروشگاه، عکس‌ها داخل فایل (AVIF، ۴۴۰ پیکسل)؛ بدون اینترنت |
| تک‌فایلی آنلاین | `python scripts/build_standalone.py --mode online` → `dist/regaal-online.html` | همه‌ی محصولات؛ عکس‌ها از سایت فروشگاه‌ها (فقط با اینترنت داخل ایران) |

`npm start` از `server/start.mjs` اجرا می‌شود: اگر پروکسی تنظیم شده باشد (`HTTPS_PROXY` یا در ویندوز «پروکسی سیستم»، مثل v2rayN)،
درخواست‌های بیرونی سرور (پینترست، Claude) از همان پروکسی رد می‌شوند. نام سایت فقط در `SITE` بالای `assets/js/app.js` تعریف شده است.

## ۲. مسیر کاربر

1. **صفحه‌ی اول** — نام رگال و توضیح کوتاه روی **دیوار بی‌انتهای محصولات** همه‌ی فروشگاه‌ها (پرده‌ی تیره پشت متن برای خوانایی):
   دیوار را می‌شود کشید (با اینرسی)، با چرخ ماوس جابه‌جا کرد و کاشی‌های نزدیک ماوس بزرگ‌تر می‌شوند.
   با نوشتن در نوار، دیوار همان لحظه پر از لباس‌های مرتبط می‌شود. کلید **خانم / آقا** کنار نوار دیوار را هم فیلتر می‌کند.
2. **ورود** — قبل از هر کاری: شماره موبایل ← کد ۵ رقمی (پر شدن خودکار، شمارش معکوس ارسال دوباره).
3. **مشاوره** — جمله‌ی کاربر دوباره نمایش داده می‌شود و فقط سؤال‌هایی پرسیده می‌شود که جمله جوابشان را نداده:
   مکان، سبک، **رنگ (در هر درخواست؛ پاسخ دفعه‌ی قبل از پیش انتخاب‌شده)**، فرم و پوشش، قد و وزن و سن (با سایز پیشنهادی زنده)، رنگ پوست، هوا،
   و **بودجه + «با اکسسوری / بدون اکسسوری»**. مشخصات شخصی (سبک، فرم، قد و وزن، پوست) فقط یک بار پرسیده می‌شود.
4. **نتیجه** — برداشت استایلیست (چیپ‌های قابل حذف)، گرید بنتو، **استایل کامل** به‌شکل داستان اسکرولی (سایز شما موجود است،
   گزینه‌ی دیگر، حذف/اضافه، جمع در برابر بودجه، و «خرید از …» برای هر تکه). رنگ محبوب در تکه‌ی اصلی و چند نتیجه‌ی اول می‌آید،
   مگر برای آن مناسبت مناسب نباشد (در برداشت توضیح داده می‌شود). هر درخواست چیز تازه می‌آورد: محصولات دیده‌شده امتیاز کمتری می‌گیرند
   و بین نامزدهای نزدیک کمی تصادف هست.
5. **صفحه‌ی محصول** — دکمه‌ی اصلی «خرید از {فروشگاه} ↖» مستقیم به صفحه‌ی کالا در همان فروشگاه می‌رود (سبد خرید نداریم).
6. **دوخت سفارشی** — (نوار بالا، منو، یا آخر نتیجه‌ها) کاربر دقیق می‌نویسد چه لباسی می‌خواهد ← درخواست به کلیدواژه‌ی انگلیسی
   ترجمه و در پینترست جست‌وجو می‌شود ← انتخاب یک نمونه (و در صورت تمایل «طراح هم روی طرح کار کند») ← «سفارش به خیاط» ←
   فرم اندازه‌ها (قد، وزن، عرض شانه، دور سینه، کمر، باسن، قد آستین، دور بازو، مچ، یقه، قد لباس، قد بالاتنه، فاق، قد شلوار، دور ران، دمپا)،
   جنس و رنگ پارچه، بودجه، زمان تحویل و توضیحات ← ثبت ← «سفارش‌های دوخت من» در حساب کاربری.

## ۳. کاتالوگ چند فروشگاهی

```bash
# داخل ایران: VIA_GOOGLE=0 (در PowerShell: $env:VIA_GOOGLE="0")
for s in digikala digistyle banimode bodyspinner lcman gerad hacoupian novincharm dayamod charmmashhad dorsa; do
  python scripts/stores/$s.py            # هر فروشگاه → data/stores/<store>.json
done
python scripts/stores/jeanswest.py       # از خروجی scripts/build_catalog.py
python scripts/merge_catalog.py          # همه → data/catalog.json و data/catalog.js
```

خزش دوباره بدون خطر از دست رفتن داده‌ی قبلی:

```bash
STORES_OUT=data/stores-new python scripts/stores/banimode.py --pages 417
python scripts/merge_stores.py           # اجتماع بر اساس id، داده‌ی تازه برنده → data/stores/
python scripts/merge_catalog.py
```

- `scripts/stores/common.py`: قالب مشترک محصول، تشخیص نوع و جنسیت از عنوان، دریافت مؤدبانه با تلاش دوباره و کوکی
  (DigiCDN دیجی‌کالا اول کوکی می‌گذارد و با 307 برمی‌گرداند). قیمت صفر یا منفی (تخفیف خراب فروشگاه) رد می‌شود.
  بیرون از ایران درخواست‌ها از translate.goog عبور می‌کنند؛ داخل ایران `VIA_GOOGLE=0`.
- فقط کالاهای **موجود** و فقط مد: پوشاک، کیف، کفش و اکسسوری. بازارهای بزرگ (دیجی‌کالا، دیجی‌استایل، بانی‌مد) با سقف و پرطرفدارترها؛ برندها کامل.
- عکس‌ها از سرور خود فروشگاه‌ها خوانده می‌شوند و در **اندازه‌ی هر قاب**: `imgUrl`/`imgSrcset` در `engine.js` نشانی کاتالوگ را
  به نسخه‌ی کوچک (دیوار و تخته) یا بزرگ (کارت‌ها، استایل کامل، صفحه‌ی محصول) هر فروشگاه تبدیل می‌کنند
  (دیجی‌کالا تا ۱۳۰۵، بانی‌مد و جین‌وست ۳۵۰/۶۰۰/۱۲۰۰، نوین چرم ۵۶۵/۱۰۰۰، دایامد ۵۱۲/۸۱۹ پیکسل).

## ۴. هوش مصنوعی و موتور

- **موتور داخل مرورگر** (`assets/js/engine.js`): فهم جمله‌ی محاوره‌ای (نفی، صفت‌ها، مناسبت‌های ایرانی، پوست و فرم بدن)،
  امتیازدهی، سایز از قد و وزن، بودجه‌ی کل، تنوع فروشگاه‌ها در نتایج، ساخت استایل با قواعد رنگ، اکسسوری با قواعد استایل ایرانی،
  رنگ محبوب همین درخواست (`likeFirst`)، فهرست دیده‌شده‌ها (`markSeen`) و ترجمه‌ی درخواست دوخت (`tailorQuery`).
  سبک و فرم ذخیره‌شده «ترجیح» حساب می‌شوند و وزنشان کمتر از خود جمله و مناسبت است.
- **Claude** (`server/server.mjs`): موتور داخلی نامزدها را پیدا می‌کند و Claude از میان آن‌ها (به‌علاوه‌ی اکسسوری‌های پرطرفدار)
  انتخاب و توضیح می‌دهد؛ رنگ محبوب و فهرست دیده‌شده‌ها هم به او داده می‌شود. خروجی ساختاریافته و شناسه‌ها روی سرور اعتبارسنجی می‌شوند.

| متغیر | توضیح |
|---|---|
| `ANTHROPIC_API_KEY` | بدون آن Claude خاموش است و موتور داخلی کار می‌کند |
| `KAVENEGAR_API_KEY`، `KAVENEGAR_TEMPLATE` | ارسال کد ورود با سرویس Verify Lookup کاوه‌نگار (پیش‌فرض قالب: `verify`) |
| `SESSION_SECRET` | کلید امضای نشست؛ بدون آن با هر اجرا کاربران خارج می‌شوند |
| `NODE_ENV=production` | کوکی Secure؛ بدون کلید پیامک، ورود غیرفعال می‌شود (کد آزمایشی نشان داده نمی‌شود) |
| `PORT`، `JW_MODEL` | پیش‌فرض `8080` و `claude-opus-5-5` |
| `HTTPS_PROXY` | پروکسی درخواست‌های بیرونی سرور؛ در ویندوز اگر تنظیم نشده باشد، پروکسی سیستم خوانده می‌شود |

### نقطه‌های سرور

| مسیر | کار |
|---|---|
| `POST /api/auth/otp`، `/verify`، `/logout` | ورود با موبایل و کد |
| `POST /api/stylist` | انتخاب و متن Claude (فقط برای کاربر واردشده) |
| `GET /api/me`، `POST /api/seen` | دیده‌شده‌ها و سفارش‌های هر شماره (`server/data/users.json`) |
| `GET /api/pins?q=`، `GET /api/pinimg?u=` | جست‌وجوی پینترست و عکس‌هایش از راه سرور (کش در `server/data/`) |
| `GET`/`POST /api/orders` | سفارش‌های دوخت؛ هر سفارش در `server/data/orders.jsonl` هم برای کارگاه ثبت می‌شود |

## ۶. پیش از راه‌اندازی عمومی

نسخه‌ی فعلی برای **ارائه به سرمایه‌گذار** است؛ این موارد پیش از راه‌اندازی عمومی قطعی می‌شوند:

- **مجوز فونت‌ها:** یکان بخ و مربع فونت‌های تجاری‌اند (فونت ایران)؛ برای انتشار عمومی مجوز لازم است. تنور سنس و پاپینز آزادند (OFL).
- **داده‌ی فروشگاه‌ها:** برای انتشار عمومی، توافق با فروشگاه‌ها یا همکاری در فروش (affiliate)؛ پیوندها مستقیم به صفحه‌ی محصول در همان فروشگاه می‌روند.
- **پینترست:** جست‌وجو از راه داخلی سایت پینترست است و رسمی نیست؛ برای راه‌اندازی عمومی API رسمی (دسترسی partner) یا منبع مجاز دیگری لازم است.
  پینترست در ایران فیلتر است، پس سرور اصلی باید بیرون از ایران باشد یا به پینترست دسترسی داشته باشد.
- **دامنه:** `regaal.ir` — قبل از راه‌اندازی در nic.ir ثبت شود.
